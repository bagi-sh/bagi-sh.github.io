## Arquivos de Configuração Esperados
1. `astro.config.mjs` pré-configurado com a integração do i18n e renderização de Markdown (Shiki para sintaxe de código em C/C++/Bash).

3. Um repositório de arquivos de exemplo em `src/content/` (mínimo de 1 post de microblog e 1 doc em cada idioma) para permitir a execução imediata de `npm run dev`.
